ALFRED ENTERPRISE COMBINED WEBSITE + ANDROID APP

index.html is the main website and app home page.
shop.html contains the product catalogue, cart, checkout, WhatsApp ordering, and order-reference enquiry.
alfred-products-poster.png is the main site's product poster.
manifest.webmanifest, sw.js, and icon.svg support the installable app.

To update the existing app on Netlify: extract this ZIP, then upload the extracted site folder contents to the existing app site's Deploys page. Keep all files together at the published root. Wait for publishing, then refresh/reopen the installed app.

The app opens to the main website. Use Shop & Order to reach shopping and tracking. Order status is confirmed manually through WhatsApp; there is no automatic live status database.
